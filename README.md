# WAC-Bootstrap

A lightweight bootstrapper for workstation setup and configuration.

## Checkliste: Nicht im öffentlichen Repository ablegen

- [ ] Passwörter, API-Schlüssel, Tokens oder andere Zugangsdaten
- [ ] Private SSH-/GPG-Schlüssel, Zertifikate oder Wiederherstellungscodes
- [ ] Persönliche Daten wie Adressen, Telefonnummern oder private E-Mail-Adressen
- [ ] Interne URLs, Hostnamen, IP-Adressen oder Netzwerkkonfigurationen
- [ ] Vertrauliche Unternehmens- oder Kundendaten und interne Dokumente
- [ ] Lokale Konfigurationsdateien mit persönlichen oder vertraulichen Angaben
- [ ] Backups, Datenbank-Dumps oder andere Dateien mit nicht öffentlichen Daten

Vor jedem Commit neue und geänderte Dateien auf vertrauliche Inhalte prüfen. Geheimnisse gehören in einen Secret-Manager oder in lokale, nicht versionierte Dateien.
